# 食谱小程序 - 产品需求文档 (PRD)

## 1. 产品概述
一款精美的食谱发现小程序，帮助用户探索世界各地的美食食谱。通过第三方 API 获取丰富的食谱数据，提供搜索、分类浏览、详情查看等核心功能。
- 目标用户：美食爱好者、家庭厨师、想要尝试新菜谱的人群
- 核心价值：发现灵感、学习烹饪、探索全球美食

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客用户 | 无需注册 | 浏览所有食谱、搜索、收藏（本地存储） |

### 2.2 功能模块
1. **首页**：精选食谱展示、分类导航、搜索入口
2. **分类页**：按食材/菜系/地区分类浏览
3. **搜索页**：关键词搜索、搜索历史
4. **详情页**：食谱详情、食材清单、烹饪步骤、收藏功能
5. **收藏页**：本地收藏的食谱列表

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 精选推荐 | 展示随机精选食谱卡片，支持点击查看详情 |
| 首页 | 分类导航 | 横向滚动分类入口（按地区、食材类型等） |
| 首页 | 搜索入口 | 搜索框，点击跳转搜索页 |
| 分类页 | 分类列表 | 网格展示各分类，点击进入分类详情 |
| 分类页 | 分类食谱 | 展示该分类下的所有食谱 |
| 搜索页 | 搜索框 | 输入关键词搜索食谱 |
| 搜索页 | 搜索历史 | 展示最近搜索记录（本地存储） |
| 搜索页 | 搜索结果 | 网格展示匹配的食谱卡片 |
| 详情页 | 食谱封面 | 大图展示成品效果 |
| 详情页 | 基本信息 | 菜名、来源地区、分类标签 |
| 详情页 | 食材清单 | 所需食材及用量列表 |
| 详情页 | 烹饪步骤 | 图文步骤说明（跳转原链接） |
| 详情页 | 操作按钮 | 收藏/取消收藏、分享功能 |
| 收藏页 | 收藏列表 | 展示已收藏的食谱卡片 |
| 收藏页 | 空状态 | 无收藏时的引导提示 |

## 3. 核心流程

### 3.1 用户浏览流程
用户打开小程序 → 首页展示精选食谱 → 点击分类查看更多 → 选择感兴趣的食谱 → 查看详情 → 收藏或开始烹饪

### 3.2 用户搜索流程
用户点击搜索 → 输入关键词 → 展示搜索结果 → 选择食谱查看详情 → 收藏或返回

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：简约现代风格，黑白灰为主色调，注重留白和排版
- **主色调**：#000000（纯黑）用于标题，#FFFFFF（纯白）作为背景
- **辅助色**：#666666（中灰）用于正文，#E5E5E5（浅灰）用于分隔线和边框，#1A1A1A 用于强调元素
- **按钮风格**：方形或微圆角按钮，黑色填充白色文字，hover 时背景变深灰
- **字体**：使用 DM Sans 作为主字体，简洁现代无衬线风格
- **布局风格**：网格布局，大量留白，卡片无边框或细边框，干净利落
- **图标风格**：细线性图标，黑色或灰色

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 首页 | 精选推荐 | 网格布局，食谱图片+名称，hover 时图片轻微变暗 |
| 首页 | 分类导航 | 横向滚动文字标签，选中态下划线 |
| 首页 | 搜索入口 | 方形搜索框，细边框，带搜索图标 |
| 分类页 | 分类列表 | 网格卡片，分类名称居中，细边框 |
| 搜索页 | 搜索框 | 固定顶部，带清除按钮 |
| 搜索页 | 搜索历史 | 横向标签列表，点击可快速搜索 |
| 详情页 | 食谱封面 | 全宽大图，无遮罩 |
| 详情页 | 食材清单 | 两列布局，食材名和用量，细分隔线 |
| 详情页 | 烹饪步骤 | 编号列表，带链接跳转 |
| 收藏页 | 收藏列表 | 与首页一致的网格布局 |

### 4.3 响应式设计
- **桌面优先**：最大宽度 1280px，居中显示，大量留白
- **平板适配**：2列卡片布局
- **移动端适配**：单列卡片，底部导航栏，触摸优化

### 4.4 动效设计
- 页面加载：简洁渐入
- 卡片悬停：轻微变暗 + 标题下划线
- 页面切换：淡入淡出
- 收藏按钮：图标切换动画
